## New Feature - PDC(Parking Distance Control)

![Image](https://github.com/user-attachments/assets/fc92afea-4997-4961-9d76-4433380a61e5)

PDC represents information about the rear distance of a vehicle. This feature is activated only R gear mode. The system utilizes SOME/IP to visualize the distance in three stages based on the distance data received from the Instrument Cluster (IC).
